# ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/AniketTribhuvan/Python_OOP.git
```

Navigate into the project:

```bash
cd Python_OOP
```

(Optional) Run static type checking:

```bash
mypy --strict .
```

Run any practice file:

```bash
python filename.py
```
